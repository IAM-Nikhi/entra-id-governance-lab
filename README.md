# Microsoft Entra ID Governance Lab

Covers users, groups, RBAC, access reviews, Conditional Access, MFA, PIM concepts, stale guests and privileged role governance.

## Exercises
1. Export group membership
2. Review directory role assignments
3. Identify stale guests
4. Design Conditional Access policy intent
5. Explain emergency access exclusions
6. Review privileged roles
7. Simulate access-review decisions

## Policy Design Example
Require MFA for administrators and external users, block legacy authentication, require compliant devices for sensitive apps and test in report-only mode first.
